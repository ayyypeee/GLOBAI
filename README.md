# GloBai

A student and teacher dashboard web app for tracking grades, attendance, quizzes, and grade concerns.

## Tech stack
- Frontend: React + Vite
- Backend: Spring Boot (Java), in the `academiko` folder

## How to run

### Backend
```
cd academiko
./mvnw spring-boot:run
```
Runs on http://localhost:8080

### Frontend
```
npm install
npm run dev
```
Usually runs on http://localhost:5173

## Demo accounts
- Student: `student` / `12345`
- Teacher: `teacher` / `12345`

## Features
- Login (done)
- Dashboard
- Attendance
- Quizzes, grade concerns, notifications (in progress)
